# Axivion Suite configuration (optional, license-bound)

MISRA C++ 2023 + CWE + Qt rulesets, clone/cycle/dead-code detection and
architecture views for RailDeck Pro, uploaded to a local dashboard.

- `./axivion/start_analysis.sh` — one run at a time (flock); skipped cleanly
  when `~/bauhaus-suite` is not installed. Exports `RAILDECK_UI=qt` so the
  fetched LVGL third-party sources stay out of the MISRA analysis.
- Configuration layers (see `axivion_config.json`): `rule_config.json`
  (rulesets), `compiler_config.json` (generated by `gccsetup` — regenerate
  after a compiler update), `ci_config.json` (project + dashboard), and
  `external_import.py` (imports the logs from `tools/static_analysis.sh` and
  `tools/sanitize.sh` in `analysis-results/` onto the dashboard as providers
  cppcheck / clang-tidy / clazy / gcc-analyzer / codespell / asan-ubsan /
  tsan / valgrind).
- Ported from a sibling project; the rule selection is project-independent.
  Validate the first run on this repository before trusting the numbers.

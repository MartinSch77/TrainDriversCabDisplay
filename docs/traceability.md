# Traceability

@page traceability Traceability Matrix

The requirements ↔ design ↔ test-spec ↔ test-result matrix is generated by
`tools/trace_report.py` into `docs/traceability.html` (self-contained HTML).

- <a href="../traceability.html">Open the current traceability matrix</a>
  (run `python3 tools/trace_report.py` after `tools/run_tests.sh` to refresh)

The report exits non-zero on **hard gaps** (spec'd test without
implementation, implemented test without spec, broken id references) and
lists requirements without automated tests as **open coverage gaps** — the
honest to-do list rather than a hidden exclusion.
